# Vercel 發布驗證紀錄

## 2026-08-27：GitHub main production deployment

已確認 Vercel production 網域的根路徑回傳 HTTP 200，回應包含「國中數學解題教練」Vite HTML；`/api/trpc/system.health` 同樣回傳 HTTP 200 與 `{ "ok": true }`。這表示 Vercel 的靜態 SPA fallback 與 Express／tRPC Function 均已成功發布。

在未登入的瀏覽器視覺檢查中，HTML 已載入但 React 介面尚未顯示任何互動元素；等待模組載入後仍相同，且 browser console 未出現執行錯誤。`document.scripts` 顯示主 JavaScript 模組已列入頁面，但 `#root` 的 HTML 與文字皆為空，因此需再驗證正式網域實際回傳的 bundle 是否為本次建置輸出。確認 bundle 正確後，需確認 Vercel Production 是否已設定 `VITE_SUPABASE_URL` 與 `VITE_SUPABASE_PUBLISHABLE_KEY`；兩者是瀏覽器端 Supabase Magic Link 初始化所必需的公開設定。伺服器端 `SUPABASE_URL`、`SUPABASE_SECRET_KEY`、`SUPABASE_DB_URL` 與 `GEMINI_API_KEY` 亦需於 Vercel Production 個別設定，且不可寫入 Git 或前端程式碼。
